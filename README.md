### Apps

**[DemoDog](https://github.com/justynroberts/demodog)** is a screen recorder for macOS that edits itself. Record, and it comes back with the zooms already placed from what you actually did, the cursor redrawn and smoothed rather than baked in, and your camera in a bubble that gets out of the way. Captions transcribe locally, nothing uploaded.

**[Termite](https://github.com/justynroberts/termite)** is a terminal client that doesn't assume you only have one server. SSH in tabs and split panes, SFTP, port forwarding, and a host vault with agent, key and bastion support. Run a step across forty machines and watch the exit codes come back. Electron and xterm.js, macOS and Windows, MIT, no account and no telemetry.

**[Pastel](https://github.com/justynroberts/pastel)** is the missing Windows clipboard manager. Native WPF, a single 90 KB exe with no runtime to install, and it builds with the C# compiler already sitting inside Windows. Ctrl+Alt+V anywhere.

**[Murmur](https://github.com/justynroberts/murmur)** is offline push to talk dictation for macOS. Local Parakeet ASR at 0.176s latency, and nothing leaves the machine.

**[Emberline](https://github.com/justynroberts/emberline)** drives GRBL laser cutters and engravers, cross platform. Camera alignment, photo engraving, bitmap tracing, and an assistant if you want one.

### Audio

**[Happy Chopper](https://github.com/justynroberts/happychopper)** is a beat slicer and pattern studio in a browser tab. Drop a loop in and it works out the tempo, finds the downbeat and cuts to the grid. Rearrange the slices, reverse them, stutter them, then point the same pattern at a completely different loop and hear it re-chopped. Four tracks, scenes, bounce to WAV. All Web Audio, nothing uploaded.

**Reach for the Lasers** is a trance lead generator, which is exactly as self indulgent as it sounds and I use it constantly.

**[eightbar](https://github.com/justynroberts/eightbar)** is natural language music production for Ableton Live 12. Ask for it and it plays.

Plus an 808 and a 909, either sampled or modelled from the circuits, and a MIDI controller driven by webcam hand tracking. All of it live at [portfolio.apps.fintonlabs.com](https://portfolio.apps.fintonlabs.com), no sign-up wall.

### Operations and hardware

**[OTLPgen](https://github.com/justynroberts/OTLPgen)** is a single binary OTLP generator for logs, metrics and traces, pointed at whichever backend you're evaluating that week. Grafana, Elastic, Datadog, Honeycomb, New Relic.

**[NeoDeck](https://github.com/justynroberts/NeoDeck)** is SSH client firmware for the LilyGo T-Deck Plus. A real terminal on an ESP32-S3, Matrix UI, on-device Claude, and a browser flasher so you don't have to think about toolchains.

Also a PagerDuty dashboard on a ten dollar ESP32 with tap to ack, and rather more Rundeck and Terraform than is strictly healthy.

Happy to talk Rundeck, PagerDuty automation, MCP servers, or agentic systems where someone has thought about the guardrails. Less happy to talk to recruiters.
